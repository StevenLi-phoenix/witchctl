# 在真游戏里用奈奈「厄运魔能」打法通关（手动，不需要任何工具）

适用于已经转存了本项目档案的 Steam 真游戏（档案里局外成长全部解锁、真理充足、仓库里预存了若干张「厄运盛宴」）。
这套打法 bot 已打通关多次：lab 里三局，真 Steam 游戏里一局（2026-10-19，14 场战斗，吞噬 11 次，奈奈没死过；日志：`docs/runs/`）。用工具自动打的做法见 README「Development」末段。数据来源和原理：项目 `CLAUDE.md` 陷阱 38–40。

## 开局前（出发前界面）
1. 模式：**经典肉鸽**。
2. 职业：**奈奈**（「出发前准备」→ 角色）。
3. 搭档：**匣上黑猫**（战备页签；开局给 70 层重生，相当于一条命）。
4. 卡包：打开 **蛇自阴影中袭来**（卡包页签，至少保持 6 个开启）。
5. 难度词条保持清空（保证"轻松"）。

## 路线
- 第一次自己铺路时，**把「一息安隅」（休息室）放在第一格**。保险箱只在休息室里有。

## 第一个休息室：取出自制卡
1. 点休息室里的**保险箱**。
2. 在牌列表里找到「**厄运盛宴**」（费用 0，卡面是"对自己添加 999 层的毒素、流血、易伤……"）。
3. **右键 → 移动**。⚠️ 不要点「丢弃」，会销毁这张卡。
4. 顺手点「取出金钱」把金币带出来（每个休息点有上限）。
5. 关闭保险箱，吃完食物，继续。
- 这张卡**每局用完就没了**，一局取一张。仓库里预存了多张，用完再进大厅「储藏室 → 创造魔法」造新的：
  10 种负面 buff（毒素 流血 易伤 灼烧 失能 遗忘 腐朽 混乱 无力 失格）各 999 层，对象「自己」，费用 0，等阶 1，花 50 真理。

## 每场战斗（顺序很重要）
1. **先打出「厄运盛宴」，然后立刻用技能「可食用厄运」，目标选自己。** 两步必须连着做：
   - 打出牌之后身上挂满 999 层毒/流血等，不吃掉会很快死；
   - **技能还在冷却（CD 5 回合）时不要打出这张牌**。
2. 吃完后「厄运魔能」增加，最大生命永久增加（173 → 442 → 822 → 1292 → 2409 → … 一局涨到约 2 万）。
3. 吃过之后再用技能「**灾祸具现化**」（变身，CD 2）：获得等同厄运魔能的临时力量/感知，每次出牌对全体敌人再造成最大生命 2% 的伤害。
   Boss 往往一击就倒。**建议第 3 回合前先把吃的做完再变身**，前几场战斗不要急着变身——变身会让战斗一两回合就结束，吃的次数少了，血量就长不起来。
4. 牌组保持精简（≤ 20 张）：想吃的那张牌被抽到得越频繁，成长越快。
5. 选牌优先：复仇短匕（最大生命 10% 的伤害）、绯咏弦奏、血契重锋、复仇链枪。

## 几个陷阱
- 失心魔女（第一个大 Boss）会复制你的所有 buff，血量没长起来前别硬拼。
- 重生只算一条命（`重生保险` 对最终首领无效）；不要指望复活。
- 把鼠标悬停在卡牌上能看到完整描述；吞噬技能在技能栏，选「自己」那个目标。
